# VOD 페이지 설계

**날짜:** 2026-06-24  
**범위:** ChzzOven의 VOD 검색·탐색 기능을 Chzzwit에 통합 (Phase A — 핵심 기능만)

---

## 목표

피드(`/`)와 별개의 `/vod.html` 페이지를 추가한다.  
팔로우(localStorage `cf_channels`)에 추가된 채널의 VOD를 카테고리/키워드로 필터링해서 그리드로 표시한다.

---

## 아키텍처

변경 범위:

```
backend/
  chzzkApi.js   ← fetchChannelVods(channelId, { page, size }) 추가
  server.js     ← GET /api/vods 엔드포인트 추가
  store.js      ← VOD 캐시 추가 (채널별 30분 TTL)

frontend/
  vod.html      ← 새 페이지
  vod.js        ← VOD 페이지 로직
  style.css     ← VOD 카드·사이드바 스타일 추가
  index.html    ← 상단바 우측에 "VOD" 링크 버튼 추가

extension/      ← 변경 없음
```

---

## 데이터 흐름

1. `/vod.html` 접근 → localStorage `cf_channels` 로드
2. `GET /api/vods?channelIds=...` 호출
3. 백엔드: 채널별 최대 5개 동시 수집(fetchPooled 패턴 재사용) → 시간순 정렬 반환
4. 프론트: 반환된 VOD에서 카테고리 목록 추출 → 드롭다운 구성
5. 필터링(카테고리·키워드)은 프론트 로컬 처리
6. 채널 체크박스 ON/OFF → 해당 채널 VOD 표시/숨김 (로컬)

---

## 백엔드 API

### `GET /api/vods`

| 파라미터 | 설명 |
|---|---|
| `channelIds` | 쉼표 구분 채널ID 목록 |
| `page` | 페이지 번호 (기본 0) |
| `size` | 페이지당 항목 수 (기본 12) |

**응답:**
```json
{
  "ok": true,
  "vods": [
    {
      "videoNo": "1234567",
      "channelId": "abc123",
      "channelName": "스트리머명",
      "title": "오늘의 방송",
      "thumbnailImageUrl": "https://...",
      "duration": 5400,
      "category": "리그 오브 레전드",
      "publishDateAt": "2026-06-24T12:00:00+09:00",
      "readCount": 12000,
      "tags": ["태그1", "태그2"]
    }
  ]
}
```

**치지직 API:**
```
GET api.chzzk.naver.com/service/v1/channels/{channelId}/videos?page={n}&size=12
```
인증 불필요 → 백엔드 직접 호출 가능.

**캐싱:** page=0만 채널별 30분 TTL로 캐싱. 이후 페이지는 직접 호출.

## 프론트엔드 레이아웃

### 상단바 (1줄, 피드·VOD 공통 구조)
```
[☰] Chzzwit  │  [카테고리▼] [제목/태그 검색...]  │  [피드] [팔로우 가져오기]
```
- 피드 페이지: 우측에 `VOD` 링크 버튼 추가
- VOD 페이지: 우측에 `피드` 링크 버튼 표시, 카테고리·검색 인풋 포함

### 전체 레이아웃
```
┌─────────────────┬──────────────────────────────┬───────────────┐
│ 채널 선택       │       VOD 카드 그리드         │    광고       │
│ N / 전체        │                               │  (200×200)    │
│ [전체] [해제]   │  ┌─────┐ ┌─────┐ ┌─────┐    │  (200×400)    │
│ ─────────────   │  │     │ │     │ │     │    │               │
│ ☑ 채널1  12개   │  │1:30 │ │45:20│ │2:10 │    │               │
│ ☑ 채널2   8개   │  ├─────┤ ├─────┤ ├─────┤    │               │
│ ☒ 채널3   0개   │  │채널명│ │채널명│ │채널명│   │               │
└─────────────────┴──────────────────────────────┴───────────────┘
```

### 좌측 사이드바
- `N / 전체` 카운터 (선택된 채널 수 / 전체)
- 전체선택 / 전체해제 버튼
- 채널별 체크박스 + VOD 개수 표시
- 체크 해제 → 해당 채널 VOD 그리드에서 숨김 (로컬 필터, 재요청 없음)
- 피드 사이드바와 동일한 토글(☰) 및 모바일 backdrop 지원

### VOD 카드
```
┌──────────────────────┐
│   [썸네일 이미지]    │
│              1:30:45 │  ← 재생시간 우측 하단 오버레이
├──────────────────────┤
│ 채널명               │  ← 클릭 시 치지직 채널 페이지 새 탭
│ VOD 제목 (2줄 말줄임)│
│ [카테고리]           │
│ 조회 1.2만 · 2일 전  │
└──────────────────────┘
```
- 카드 클릭 → `https://chzzk.naver.com/video/{videoNo}` 새 탭

### 필터
- **카테고리**: 수집된 VOD의 category 필드에서 중복 제거 후 `<select>` 드롭다운 구성
- **키워드**: 제목 + 태그 대상 실시간 필터링 (300ms debounce, 로컬)
- 채널 없을 때: "피드에서 채널을 추가하면 VOD가 여기 모여요" 안내
